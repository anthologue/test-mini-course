# CLAUDE.md

## Tech Stack

- Plain HTML, CSS, and JavaScript only.
- No frameworks, no build step. Files are opened directly in a browser.

## Project Structure

The repository is nearly empty for now. As it grows, keep it simple:

- `index.html` — the main page (at the top level)
- `css/` — stylesheets
- `js/` — JavaScript files
- `CLAUDE.md` — this file

Update this section whenever files or folders are added.

## Key Requirements

1. Every page must be responsive and work on desktop, tablet, and phone.
2. Users can toggle between a light and a dark theme. The default is the light theme.
